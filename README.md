# Zafiro

Sistema de gestión agronómica: campos, lotes, aplicaciones, recetas, lista de precios y costos.

## Empezar

```bash
npm install
cp .env.example .env.local   # completar con los datos de Supabase
npm run db:migrate           # crea las tablas (habilita PostGIS)
npm run dev
```

Contexto, decisiones y próximos pasos: [`docs/DECISIONES.md`](docs/DECISIONES.md).
